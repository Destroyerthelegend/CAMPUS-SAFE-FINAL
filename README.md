# CAMPUS-SAFE

## Project Overview
CAMPUS-SAFE is a software-based simulation of priority-based emergency communication using wireless mesh networking concepts.

## My Contribution — Kavin
- `core/topology.py` — Network topology representation.
- `core/routing.py` — Route selection.
- `core/failure.py` — Failure handling and alternate-route recovery.

## My Contribution — Prithvi

- `core/queueing.py` — Implements priority-based packet queueing.
- `core/channel.py` — Handles channel simulation and communication.
- `metrics/collector.py` — Collects and calculates simulation performance metrics.
- `experiments/run_experiment.py` — Runs network simulation experiments.
- `experiments/plots.py` — Generates plots to visualize experiment results.
