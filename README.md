# CAMPUS-SAFE

## Project Overview
CAMPUS-SAFE is a software-based simulation of priority-based emergency communication using wireless mesh networking concepts.

## My Contribution — Kavin
- `core/topology.py` — Network topology representation.
- `core/routing.py` — Route selection.
- `core/failure.py` — Failure handling and alternate-route recovery.

## Team Contributions
- **Kavin:** Topology, routing, failure recovery, and integration.
- **Prithvi:** Priority queueing, channel simulation, metrics, and experiments.

## Project Structure
- `core/` — Core network simulation modules.
- `metrics/` — Performance metric collection.
- `experiments/` — Simulation experiments and plotting.
- `tests/` — Automated tests.

## Status
The project is being assembled for integration. The complete simulation will be tested after all modules are added.
